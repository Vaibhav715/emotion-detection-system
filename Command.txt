1. In Windows (Standalone Command Prompt / CMD)
Open Command Prompt (press Win + R, type cmd, and hit Enter), navigate to your project folder, and run these commands in order:
------start------
:: Navigate to your project folder
cd /d "D:\Emotion Detection System"

:: 1. Create the virtual environment
python -m venv venv

:: 2. Activate the virtual environment
venv\Scripts\activate.bat

:: 3. Upgrade pip
python -m pip install --upgrade pip

:: 4. Install all required packages
pip install flask flask-cors pandas scikit-learn joblib transformers torch

:: 5. Silence Hugging Face symlink warnings
set HF_HUB_DISABLE_SYMLINKS_WARNING=1

:: 6. Train the initial Scikit-Learn baseline (optional)
python train.py

:: 7. Start the Flask application
python app.py

--------------------------------------------------------------------------------------------------------------------------------------

2. In VS Code (Built-in PowerShell Terminal)
Open your project folder in VS Code, open the built-in terminal (`Ctrl + `` or Terminal > New Terminal), and run these commands:
-----start-----
# 1. Allow running local scripts in PowerShell (run once per terminal session)
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned

# 2. Create the virtual environment
python -m venv venv

# 3. Activate the virtual environment
.\venv\Scripts\Activate.ps1

# 4. Upgrade pip
python -m pip install --upgrade pip

# 5. Install all required packages
pip install flask flask-cors pandas scikit-learn joblib transformers torch

# 6. Silence Hugging Face symlink warnings
$env:HF_HUB_DISABLE_SYMLINKS_WARNING="1"

# 7. Train the initial Scikit-Learn baseline (optional)
python train.py

# 8. Start the Flask application
python app.py
